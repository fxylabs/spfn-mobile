# Hybrid WebView reference — placeholder

Nothing here yet. The hybrid adapters expose no bridge at all: the allowed message-name
list is empty on both platforms, by design.

When this example exists it must demonstrate the negative properties as clearly as the
positive ones — no redirect-based auth route, no credential injection into web content,
and no generic JavaScript passthrough. Those are the properties the compatibility gate
verifies, so the example should make them visible rather than merely not violate them.
